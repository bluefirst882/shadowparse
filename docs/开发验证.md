## 提交检查

安装根目录依赖后，Husky 会在提交前执行 `lint-staged`。JavaScript、Vue、JSON、CSS、YAML 和 Markdown 文件使用 Prettier；Python worker 运行语法编译检查。

```powershell
D:\program\nodejs\npm.cmd install --cache .npm-cache
D:\program\nodejs\npm.cmd run format:check
D:\program\anaconda\python.exe -m py_compile workers/whisper_worker.py
```

## 完整验证

```powershell
$env:JAVA_HOME='D:\program\idea\jbr'
.\mvnw.cmd -f backend\pom.xml verify
D:\program\nodejs\npm.cmd --prefix frontend run build
```

本机没有 MySQL 时，`MySqlMigrationTest` 会跳过。CI 启动 MySQL 8.4，执行 Flyway 迁移及完整后端验证。

> Spotless 使用 google-java-format，依赖标准 `javac` 内部 API；JetBrains Runtime（JBR）会触发
> `NoSuchMethodError`。跑 `verify` 时请把 `JAVA_HOME` 指向标准 JDK 21（如 Temurin）。

## 2026-09-27 章节引文闸门与跨块二次合并实测

```powershell
.\mvnw.cmd -f backend\pom.xml verify
npm --prefix frontend run build
docker compose build backend
docker compose up -d --wait
```

- 后端：`Tests run: 71, Failures: 0, Errors: 0, Skipped: 3`（3 项 MySQL 集成测试未配置 `MYSQL_TEST_URL` 时跳过），Spotless 通过。
  新增 `LlmClientSummaryTest`（3 项：多块触发一次合并调用且要点超过阈值不被截断、单块不发起合并且合并仅标点/空白不同的要点、`dedupeKeyPoints` 单元）；
  `ResultValidatorTest` 增补引文核验用例（编造引文被拒并断言 `reason=quote_mismatch` 且错误信息含章节与引文、引用他人片段引文被拒、缺引文被拒、仅标点/空白差异被接受）；
  `WorkbenchMetricsTest` 增加校验拦截计数的计数与 Prometheus 导出名断言。
- 前端：`vue-tsc` 与 Vite 生产构建通过（`dist/assets/index-*.js` 361.08 kB / `index-*.css` 96.82 kB），章节列表新增原文引证展示。
- 容器：`up -d --wait` 后 backend / frontend / mysql / prometheus / grafana 全部 `healthy`。
- 真实重跑（沿用已转写任务，不重新转写，只重跑摘要）：
  - `POST /api/tasks/f1094e67-33da-4038-9935-25557bc50288/retry` → HTTP `200`，轮询后 `COMPLETED/COMPLETED`，57 个片段生成 6 个要点、6 个章节；
  - `POST /api/tasks/6493bbed-aa77-4707-abec-41a5e03f292d/retry` → `COMPLETED/COMPLETED`，105 个片段生成 8 个要点、11 个章节。
  - 独立复核：用与闸门相同的归一化规则逐个拼接章节引用的来源片段文本，断言 `quote` 均被包含，6 个章节全部 `quoteContained=True`。
  - 真实引文样例（第 5 章，来源片段 4093-4102）：`so i don't care it's uh it is working like that for hundreds of years doesn't matter`。
- 真实指标佐证闸门与重试确实生效（本次重启后的进程内累计）：`/actuator/prometheus` 读到
  `workbench_llm_requests_total{operation="summarize",outcome="success"}=4`、`workbench_llm_retries_total{operation="summarize"}=2`、
  `workbench_llm_validation_failures_total{reason="invalid_chapter_timing"}=1`。即其中一条任务首次输出的章节时间轴未通过校验、
  被闸门拦下并触发带失败原因的重试，最终仍达到 `COMPLETED`；本轮 `quote` 闸门未被命中（模型给出的引文均逐字出自原文）。
- 结论：带 `quote` 要求的新提示词下，真实模型仍能稳定产出通过校验的结果，正常样本未被误杀；反幻觉闸门未出现「形同虚设」的放宽。
