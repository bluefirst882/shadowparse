## 2026-09-20 MySQL 迁移复验

- 在 Docker MySQL 8.4 的空数据库中执行 `MySqlMigrationTest`：Flyway 从空 schema 依次应用 V1、V2，创建 `tasks`、`transcript_segments`、`task_results` 三张核心表，测试通过。
- Flyway 日志提示当前 Flyway 版本尚未声明测试 MySQL 8.4；本次仅记录实际迁移结果，不将其外推为所有 MySQL 8.4 环境的兼容性保证。
- 本机 `3306` 上的既有开发库记录到 V3 `add online source`，包含当前仓库范围外的 `source_url` 列；它未用作本次干净迁移证据。复验容器当前保留在本机 `3307` 端口。
- 在同一 MySQL 8.4 容器中，两个线程同时对同一个随机任务 ID 执行条件领取；恰好一个 `claimForProcessing` 返回成功，测试结束后删除该测试任务。
- 在同一 MySQL 8.4 容器中，先保存一条旧转写，再提交一个含非法空文本片段的批量替换。插入触发非空约束失败后，原转写片段仍完整存在，验证片段删除和整批插入处于同一事务并已回滚。
- 单线程执行器与容量为 1 的等待队列均被占满时，再导入视频仍会保存任务为 `QUEUED`，并返回“队列已满，可稍后重试”提示，避免前端因拿不到任务 ID 而无法恢复。
- 使用同一容器启动 Spring Boot 进行 API 冒烟：`GET /api/tasks` 返回 200 和空列表；取消不存在任务返回 404。测试服务随后停止，未上传或处理视频。
- 通过真实 API 上传一个 1 秒、仅含视频流的 MP4：任务在 `AUDIO_EXTRACTION` 阶段失败，错误信息包含 FFmpeg 的 `Output file #0 does not contain any stream`；删除该任务后查询返回 404，测试存储目录无剩余视频或 WAV 文件。
- 通过真实 API 上传一个内容非法、但扩展名与 MIME 均为 MP4 的小文件：任务在 `AUDIO_EXTRACTION` 阶段失败，错误信息包含 FFmpeg 的 `moov atom not found` 与 `Invalid data found when processing input`；删除后查询返回 404，测试存储目录无残留文件。
- 通过真实 API 上传两个 30 秒、带音轨的测试视频：首个任务进入 `PROCESSING`，第二个任务保持 `QUEUED`。分别取消执行中任务和排队任务后，两者均为 `CANCELLED`；删除后测试存储目录无残留视频或 WAV 文件。
- 通过真实 API 上传一个 30 秒、带音轨的视频并等待其进入 `PROCESSING` 后停止服务。确认没有遗留 `whisper_worker.py` 进程；重启服务后，该任务被重新调度并最终达到 `COMPLETED` / `SUMMARY`（未配置云端摘要时保留本地转写提示）。删除后查询返回 404，测试存储目录无残留文件。

## 2026-09-20 本地转写样本

- 输入：一个 356.78 秒英文 MP4 的前 30 秒，FFmpeg 提取为 16 kHz 单声道 WAV（960,076 bytes）。
- 环境：NVIDIA GeForce RTX 4060 Laptop GPU，Whisper `turbo`，CUDA 推理。
- 结果：共生成 5 个带时间戳片段；从启动 Python worker 到获得 JSON 结果耗时 15.05 秒，包含模型加载。
- 该结果仅描述一个 30 秒样本，不能外推为完整视频、其他语言、冷启动或并发场景下的性能。

## 2026-09-21 中文真实视频样本

- 输入：`E:\Downloads\Video\27210678708-1-192.mp4`，文件大小 33,507,395 bytes，媒体时长 355.947 秒，视频 H.264、音频 AAC。
- 环境：本地 Whisper `turbo`，NVIDIA GeForce RTX 4060 Laptop GPU，CUDA 推理；通过工作台 API 上传，FFmpeg 抽取 16 kHz 单声道音频。
- 结果：从上传到任务达到 `COMPLETED/SUMMARY` 约 58 秒，持久化 250 个带时间戳片段。未配置云端密钥，任务提示可单独重试摘要与章节生成。
- 发现：Whisper 在视频尾部返回了部分超出媒体时长的片段（最长约 385.56 秒）。该样本证明中文转写链路可执行，但不作为章节时间轴校验通过或通用性能结论；后续需在转写落库前增加媒体时长上限裁剪或失败策略。
