# 编码规范

- 所有界面、接口错误和文档使用中文；标识符和代码注释使用清晰英文。
- 后端按领域拆分，控制器不得包含进程编排或数据库细节。
- 所有外部进程必须有超时、可取消句柄和 stderr 诊断；日志不得输出密钥或转写全文。
- 时间均使用毫秒整数保存，API 输出使用秒数；章节服务端二次校验（时间轴 + 引文逐字核验）。
- 模型输出先按 JSON Schema（`LlmJsonSchema`）做结构校验再进入业务校验；schema 是唯一来源，提示词与本地校验使用同一份原文。
- 外部依赖的降级、超时与结构失败必须可观测：打点标签只取有限枚举值，降级路径同时写 WARN 日志。
- 测试使用隔离临时目录，测试结束自动删除生成物，不删除用户导入的源文件。
