# 视频解析工作台需求

## 首版范围

- 导入本地视频，校验文件类型与大小，保存任务及原文件位置。
- 使用 FFmpeg 提取音频，CPU 环境串行执行 Python Whisper `turbo` 转写。
- 保存带开始、结束时间的转写段落；转写完成后可独立生成中文摘要、要点与章节。
- 摘要输入按完整转写片段分批，按配置的字符数上限控制单次请求；合并各批结果后再执行章节校验。
- 章节必须引用原始段落；话题章节可跨连续片段，服务端校验开始、结束时间分别位于首尾引用片段范围内。
- 支持取消、摘要单独重试或本地处理重新执行、删除、重启后重新调度、视频 Range 流及 Markdown/JSON/SRT 导出。
- 自建注册与登录（用户名 + BCrypt 密码），以无状态 JWT 鉴权；任务按账号归属，只能读写自己的任务，越权返回 `403`。

## 隐私与配置

- 任务与结果保存在本机 MySQL；视频、音频和模型文件保存在本机存储目录。
- 云端阶段只传递必要转写文本，绝不上传视频、音频或画面。
- `LLM_*` 配置仅由后端读取，密钥不可进入日志、前端或导出文件。
- 未配置密钥时显示可操作提示，用户仍能完成导入与本地转写。

## 非目标

首版不提供团队/组织级多租户、支付、在线视频下载或默认视觉分析；在线视频来源不在后续实施范围内。
