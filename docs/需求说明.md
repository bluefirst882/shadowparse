# 视频解析工作台需求

## 首版范围

- 导入本地视频，校验文件类型与大小，保存任务及原文件位置。
- 使用 FFmpeg 提取音频，CPU 环境串行执行 Python Whisper `turbo` 转写。
- 保存带开始、结束时间的转写段落；转写完成后可独立生成中文摘要、要点与章节。
- 章节必须引用原始段落，且服务端校验所有时间位于视频时长内。
- 支持取消、按阶段重试、删除、重启后继续、视频 Range 流及 Markdown/JSON/SRT 导出。

## 隐私与配置

- 任务、结果与视频文件仅保存在本机 SQLite 和存储目录。
- 云端阶段只传递必要转写文本，绝不上传视频、音频或画面。
- `CODERPLAN_*` 配置仅由后端读取，密钥不可进入日志、前端或导出文件。
- 未配置密钥时显示可操作提示，用户仍能完成导入与本地转写。
- coderplan.ai 请求协议必须以官方文档或控制台为准；未核实前不得猜测接口路径或自动切换模型，详见 `docs/coderplan-协议核查.md`。

## 非目标

首版不提供账号、多租户、支付、在线视频下载或默认视觉分析。
