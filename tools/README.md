# 工具脚本

一次性脚本与本地辅助脚本的统一入口，全部从仓库根目录执行：

```bash
npm run eval:live          # 等价 node tools/measure/eval-live.mjs
npm run screenshot         # 等价 node tools/capture/prototype.mjs
```

> 所有截图脚本输出到 `artifacts/`（已被 Git 忽略），需要留证的复制进 `docs/images/`。

## capture/ —— 截图取证

| 脚本            | 作用                                                        | 前置条件                             |
| --------------- | ----------------------------------------------------------- | ------------------------------------ |
| `prototype.mjs` | 对 `docs/prototype/video-workbench-prototype.html` 整页截图 | 仅需本机 Chrome                      |
| `frontend.mjs`  | 截图运行中的工作台，桌面 + 移动两种视口                     | 前端已启动（默认 127.0.0.1:5174）    |
| `grafana.mjs`   | 截图 Grafana 已 provisioning 的面板，作为可观测性证据       | Grafana 已启动，需管理员账号环境变量 |

## verify/ —— 浏览器端验收

| 脚本                  | 作用                                                        | 前置条件       |
| --------------------- | ----------------------------------------------------------- | -------------- |
| `realtime-upload.mjs` | 验收 SSE 推送（不再轮询）+ 分片上传进度条，跑完自动清理任务 | 前后端容器已起 |
| `task-detail.mjs`     | 截图任务详情页，用于人工核验 Top-N 类改动                   | 前后端容器已起 |

## measure/ —— 度量与压测

| 脚本              | 作用                                                              | 产出                                            |
| ----------------- | ----------------------------------------------------------------- | ----------------------------------------------- |
| `eval-live.mjs`   | 用真实 API 采样，统计当前提示词下的结构非法率（新口径 vs 旧口径） | `backend/target/eval-live-report.md` 及原始返回 |
| `sse-latency.mjs` | 实测 SSE 推送的端到端延迟，并验证未登录/他账号收不到推送          | 控制台输出                                      |

吞吐量压测脚本不在本目录，见 [`../ops/k6`](../ops/k6)。

## 根目录

| 脚本            | 作用                                                 |
| --------------- | ---------------------------------------------------- |
| `start-all.ps1` | 一键拉起全部服务（前端 / 后端 / MySQL / Whisper 等） |
| `stop-all.ps1`  | 停止服务但保留数据卷、视频与模型                     |
| `repo-peek.mjs` | 速览公开 GitHub 仓库的元信息与 README，用于选型对比  |
